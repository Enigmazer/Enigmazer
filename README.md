### 💻 Featured Projects

#### [Clef — Teaching & Course Management Platform](https://github.com/Enigmazer/clef-backend) &nbsp;|&nbsp; [Live Demo](https://clefapp.vercel.app/)

*A full-stack platform so no student ever loses track of where the class is, what's been covered, and what comes next.*

| Area | What's built |
| :--- | :--- |
| **Auth** | OAuth2 (Google + GitHub), JWT with HttpOnly cookie rotation, SMS 2FA via Twilio Verify, OAuth2-backed password reset |
| **Roles** | Context-derived — creating a subject = teacher; joining via invite code = student. Same account holds both roles |
| **Storage** | Supabase via AWS S3 SDK; backend validates uploads, issues pre-signed URLs (1-hr TTL) |
| **AI** | Gemini AI parses syllabus PDFs into structured units/topics; teacher reviews before bulk DB write |
| **Tracking** | Current/next topic pointers auto-advance on completion; drag-and-drop topic reordering |

`Java 21` `Spring Boot 3` `Spring Security` `PostgreSQL` `Supabase` `Twilio` `Gemini AI` `React 19`
